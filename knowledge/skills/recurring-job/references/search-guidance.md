# Search guidance for posts made with models

What the search engine's own guidance asks of a site that publishes posts written with model help, in our words. The blog template applies it; the pages decide, so read them, not this note, when it matters.

What the template takes from it:
- A person approves every post before it is published, metadata included: the gate before the publish step.
- A daily cadence is a ceiling, not a quota: no topic means no post, and repeated dropped runs pause the job.
- The post is written for readers, from sources, and says what it adds; the model's use alone earns nothing.

## Sources

- Google Search Central, Creating helpful, reliable, people-first content. https://developers.google.com/search/docs/fundamentals/creating-helpful-content (read 2026-10-12). basis: vendor-doc. Asks whether content is made for people first, and whether extensive automation produces it on many topics.
- Google Search Central, Google Search's guidance on using generative AI content. https://developers.google.com/search/docs/fundamentals/using-gen-ai-content (read 2026-10-12). basis: vendor-doc. Advises checking the facts of model-written content and reviewing it by hand before publishing, title and other metadata included.
- Google Search Central, Spam policies, scaled content abuse. https://developers.google.com/search/docs/essentials/spam-policies (read 2026-10-12). basis: vendor-doc. Counts using generative tools to make many pages without adding value for users as scaled content abuse.
- Google Search Central Blog, Google Search's guidance about AI-generated content (2023-02-08). https://developers.google.com/search/blog/2023/02/google-search-and-ai-content (read 2026-10-12). basis: vendor-doc. Using models gives content no special ranking gain; whether it helps people decides.
